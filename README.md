# COA Egypt — Official Executive Portfolio

منصة بورتفوليو رقمية تفاعلية حديثة وسريعة لشركة **COA Egypt (Community of Accountants)**، تم تصميمها بمعمارية بصرية متقدمة ومستوحاة من كبرى المنصات التقنية مثل Digital Harbor، مع الاحتفاظ بالخفة والسرعة الفائقة (< 0.4 ثانية تحميل) وتطبيق الهوية البصرية الرسمية للشركة.

---

## 🎨 الهوية البصرية (Brand Identity)
- **الكحلي الملكي (Royal Navy):** `#002955`
- **الأحمر القرمزي (Crimson Red):** `#F00613`
- **الأزرق السيان التكنولوجي (Electric Cyan):** `#00E5FF`

---

## 🚀 مجالات العمل الأربعة (Core Capabilities)
1. **الاستشارات المالية والضريبية (Financial & Tax Advisory)**: مراجعة قانونية معتمدة، فحص نافٍ للجهالة، تقييم الشركات، الضرائب، IFRS.
2. **منظومة وحلول أودو (Odoo ERP Solutions)**: شريك فضي معتمد (Silver Partner)، تهيئة، تطوير مخصص، فوترة إلكترونية (ZATCA Phase 2 / مصر).
3. **التحول الرقمي وهندسة العمليات (Business Transformation)**: إعادة هندسة العمليات (BPR)، إجراءات التشغيل القياسية (SOPs).
4. **أكاديمية وتدريب الشركات (COA Learning)**: تأهيل الكوادر المحاسبية والإدارية.

---

## 💻 المميزات التقنية (Key Features)
- **جولة ترحيبية 3D تفاعلية (`#dh-intro`)**: محرك Three.js WebGL خفيف مع موجة جسيمات ديناميكية وسقوط 2D احتياطي.
- **خلفية مازربورد تفاعلية (`#dh-rain`)**: مسارات دوائر مطبوعة بزوايا 45° هندسية حقيقية، معالج سيليكوني بدقة فائقة، ونبضات ليزرية حية.
- **لوحة تفاعلية بـ 3 تبويبات (Hero Stack Hub)**: بطاقة المنظومة، تيليميتري مباشر، والطرفية البرمجية الحية (COA Kernel) مع كود Bash تفاعلي.
- **مستكشف الطبقات (Stack Explorer)**: استعراض تفاعلي لأربع طبقات تقنية.
- **مصفوفة المقارنة التنافسية (Comparison Matrix)**: مقارنة ثلاثية حاسمة تبرز تفوق COA في مقابل الحلول البديلة.
- **حاسبة نطاق المشروعات (Scope Estimator)**: تقدير ذكي فوري للمدة الزمنية والحزمة والتوافق الضريبي مع زر تواصل واتساب فوري.
- **دعم ثنائي اللغة بالكامل**: عربي (RTL) / إنجليزي (LTR) فوري بدون إعادة تحميل الصفحة.
- **الوضع الليلي والنهاري (Dark / Light Mode)**: تبديل سلس مع حفظ التفضيل محلياً.

---

## 🛠️ كيفية التشغيل محلياً (Run Locally)
يمكنك فتح ملف `index.html` مباشرة في أي متصفح حديث، أو تشغيل خادم محلي سريع عبر بايثون:

```bash
# تشغيل خادم محلي
python -m http.server 3036
```
ثم فتح الرابط: `http://localhost:3036/` في المتصفح.
